# P1-2：多视图切换（卡片 / 表格）

> 2026-06-09

## Context

当前提示词列表只有卡片网格一种视图。用户管理大量提示词时（50+），卡片视图信息密度低，无法批量操作、无法按列排序。AI Gist 的同类功能支持卡片/表格/分类三种视图，本方案先实现卡片+表格切换。

## 现状追踪

### 当前实现

```
PromptList                                    — src/components/prompt/PromptList.tsx
  渲染: <div className="grid grid-cols-1 md:grid-cols-2 lg:grid-cols-3 gap-3">
  数据: 从 useAppStore() 读取 prompts, searchQuery 等
  props: onNewPrompt, onPromptClick, onToggleStar, onGenerate

PromptCard                                    — src/components/prompt/PromptCard.tsx
  渲染: Card 组件含标题、内容预览(line-clamp-2)、标签(前3个)、版本号、日期
  搜索高亮: HighlightText 组件
  交互: 收藏按钮(hover显示)、点击跳转详情

HomePage                                      — src/pages/HomePage.tsx
  组合: Header + Sidebar + MainContent { PromptList + GenerateDialog }

useAppStore                                   — src/store/useAppStore.ts
  过滤: activeSceneId, searchQuery, isStarredFilter, filterTag, dateRange
  排序: searchPrompts 按 updatedAt desc；无公共排序控制
  未存储视图模式状态
```

### 关键发现

- **无视图切换基础设施**：store 中没有 `viewMode` 状态
- **PromptList 自包含**：不接收数据 props，自行从 store 订阅
- **PromptCard 独立组件**：表格视图可直接复用其数据展示逻辑
- **FilterBar 与视图解耦**：所以视图切换不影响过滤逻辑

## 目标行为

1. PromptList 标题栏右侧增加视图切换按钮组（卡片 / 表格 两个图标按钮）
2. 卡片视图：保持现有 grid 布局不变
3. 表格视图：使用 shadcn/ui `Table` 组件，列包括名称、内容预览、标签、版本、更新日期、操作
4. 点击行 → 跳转详情
5. 视图偏好存储到 localStorage，刷新后保持
6. 搜索、过滤在两种视图下均正常工作

## 实现方案

### 1. Store 新增状态

**`src/store/useAppStore.ts`**：

```ts
// 新增字段
viewMode: 'card' | 'table';

// 新增 action
setViewMode: (mode: 'card' | 'table') => void;

// 初始化时从 localStorage 恢复
viewMode: (localStorage.getItem('ai-prompt-manager-view-mode') as 'card' | 'table') || 'card',

// setViewMode 中持久化
setViewMode: (mode) => {
  set({ viewMode: mode });
  localStorage.setItem('ai-prompt-manager-view-mode', mode);
},
```

### 2. PromptList 改造

**`src/components/prompt/PromptList.tsx`**：

```
标题行右侧增加视图切换按钮:
  [LayoutGrid图标|高亮/未高亮] [List图标|未高亮/高亮]

卡片视图 (viewMode === 'card'):
  保持现有 grid grid-cols-1 md:grid-cols-2 lg:grid-cols-3 gap-3

表格视图 (viewMode === 'table'):
  <Table>
    <TableHeader> 名称 | 内容预览 | 标签 | 版本 | 更新时间 | 操作 </TableHeader>
    <TableBody>
      {prompts.map(p => (
        <TableRow key={p.id} onClick={() => onPromptClick(p.id)} className="cursor-pointer hover:bg-accent/50">
          <TableCell>{p.name}</TableCell>
          <TableCell className="max-w-xs truncate">{p.content}</TableCell>
          <TableCell>{p.tags?.slice(0, 3).map(tag => <Badge>{tag}</Badge>)}</TableCell>
          <TableCell>{versionLabel(p)}</TableCell>
          <TableCell className="text-xs text-muted-foreground">{formatDate(p.updatedAt)}</TableCell>
          <TableCell>
            <Button variant="ghost" size="icon" onClick={e => { e.stopPropagation(); onToggleStar(p.id, !p.isStarred); }}>
              <Star className={p.isStarred ? 'fill-yellow-400 text-yellow-400' : ''} />
            </Button>
          </TableCell>
        </TableRow>
      ))}
    </TableBody>
  </Table>
```

### 3. 空状态处理

两种视图共享同一个空状态组件（当前 `PromptList` 的空状态逻辑不变）。

### 4. 响应式处理

- 表格视图在移动端（`<md`）：隐藏内容预览和标签列（用 `hidden md:table-cell`），只保留名称、更新时间和操作

## 评审发现与修订 (2026-06-09)

### 1. versionLabel() 不存在 + N+1 异步问题（阻断）

**问题**：版本号在 `PromptCard` 中通过异步 `getVersion(prompt.currentVersionId)` 获取。表格渲染 50+ 行时不能逐行异步查 DB。

**修正**：方案改为在 `loadPrompts()` 或 `PromptList` 中批量预加载版本标签。新增 `getVersionMap(promptIds: string[]): Promise<Record<string, string>>` 在 `versionService.ts`，一次性查询所有版本的 version 字段。

### 2. 缺少 shadcn Table 和 Badge 组件

**问题**：`src/components/ui/` 中没有 `table.tsx` 和 `badge.tsx`。

**修正**：实现前先执行 `npx shadcn@latest add table badge` 安装组件。

### 3. 排序功能缺失

**问题**：方案定义了表格列但无排序逻辑。

**修正（设计决策）**：P1 阶段仅实现客户端排序（`useMemo` + 点击列头切换 `sortKey`/`sortDir`），无需改动 service 层。

### 4. 表头/表体列隐藏一致性问题

**问题**：`hidden md:table-cell` 须同时应用于 `<th>` 和 `<td>`。

**修正**：抽一个 `MOBILE_VISIBLE_COLS = ['name', 'updatedAt', 'actions']` 常量，超出范围的列统一加 `hidden md:table-cell`。

### 5. getAllPrompts 无排序

**问题**：`getAllPrompts()` 不排序，表格模式下数据顺序随机。

**修正**：`loadPrompts` 中当无搜索词时默认按 `updatedAt desc` 排序。
