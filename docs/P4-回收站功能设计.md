# P4：回收站功能设计

> 日期: 2026-06-13 | 状态: 已评审修正

---

## 一、目标

提示词和场景的删除操作改为软删除：先进入回收站，30 天后自动清理。恢复操作撤销软删除。

**评审修正要点：** 同步上线场景+提示词回收站（非分阶段）；补充遗漏查询点；增加撤销 Toast；导入时剥离 `deletedAt`。

---

## 二、数据模型

### 2.1 软删除字段

```ts
// types/index.ts
interface Scene {
  // ... existing fields
  deletedAt?: number;  // null = active, timestamp = in trash
}

interface Prompt {
  // ... existing fields  
  deletedAt?: number;
}

// Version 不单独标记——跟随其 prompt。prompt 恢复时版本自动恢复。
// 硬删除 prompt 时级联硬删除其所有版本。
```

### 2.2 Dexie v4 升级

```ts
// db/index.ts
db.version(4).stores({
  scenes: 'id, name, sortOrder, createdAt, deletedAt',
  prompts: 'id, sceneId, name, *tags, isStarred, createdAt, updatedAt, deletedAt',
  versions: 'id, promptId, version, score, createdAt',
});
```

旧数据无 `deletedAt`（`undefined == null` → true），天然兼容，无需迁移脚本。

### 2.3 辅助函数（防遗漏）

```ts
// src/services/helpers.ts
export function activeOnly<T extends { deletedAt?: number }>(items: T[]): T[] {
  return items.filter(item => item.deletedAt == null);
}
```

所有查询点统一使用 `activeOnly()` 而非内联 filter，降低遗漏风险。

## 四、服务层

### 4.1 promptService.ts 新增/修改

```ts
// 查询辅助
const activePrompts = () => db.prompts.filter(p => p.deletedAt == null);

// 所有列表查询改用 activePrompts() 或 activeOnly()

// 新增
export async function trashPrompt(id: string): Promise<void> {
  await db.prompts.update(id, { deletedAt: Date.now() });
}

export async function restorePrompt(id: string): Promise<void> {
  const prompt = await db.prompts.get(id);
  if (!prompt) return;
  
  // ⚠️ 检查场景状态：如果场景在回收站，弹出对话框让用户选目标场景
  // 由调用方（UI层）处理，Service 只负责数据操作
  await db.prompts.update(id, { deletedAt: undefined });
}

export async function permanentDeletePrompt(id: string): Promise<void> {
  await db.transaction('rw', db.prompts, db.versions, async () => {
    await db.versions.where('promptId').equals(id).delete();
    await db.prompts.delete(id);
  });
}

export async function getTrashPrompts(): Promise<Prompt[]> {
  return db.prompts.filter(p => p.deletedAt != null).toArray();
}

export async function emptyTrash(cutoff?: number): Promise<void> {
  const trash = await getTrashPrompts();
  const toDelete = cutoff 
    ? trash.filter(p => p.deletedAt! < cutoff)
    : trash;
  for (const p of toDelete) {
    await permanentDeletePrompt(p.id);
  }
}

export async function getTrashCount(): Promise<number> {
  return db.prompts.filter(p => p.deletedAt != null).count();
}
```

### 4.2 sceneService.ts 新增/修改

```ts
export async function trashScene(id: string): Promise<void> {
  await db.transaction('rw', db.scenes, db.prompts, async () => {
    await db.scenes.update(id, { deletedAt: Date.now() });
    // ⚠️ 只级联标记当前活跃的 prompt（已在回收站的不重复标记）
    const prompts = await db.prompts.where('sceneId').equals(id)
      .filter(p => p.deletedAt == null).toArray();
    const now = Date.now();
    for (const p of prompts) {
      await db.prompts.update(p.id, { deletedAt: now });
    }
  });
}

export async function restoreScene(id: string): Promise<void> {
  await db.transaction('rw', db.scenes, db.prompts, async () => {
    await db.scenes.update(id, { deletedAt: undefined });
    // ⚠️ 只恢复由本场景级联删除的 prompt（同一时间戳，或直接从 active→trash 的）
    // 最简实现：恢复场景下所有 prompt（用户主动恢复场景 = 意图恢复全部）
    // 如果未来有冲突场景，可改为确认对话框
    const prompts = await db.prompts.where('sceneId').equals(id).toArray();
    for (const p of prompts) {
      await db.prompts.update(p.id, { deletedAt: undefined });
    }
  });
}

export async function permanentDeleteScene(id: string): Promise<void> {
  await db.transaction('rw', db.scenes, db.prompts, db.versions, async () => {
    const prompts = await db.prompts.where('sceneId').equals(id).toArray();
    for (const p of prompts) {
      await db.versions.where('promptId').equals(p.id).delete();
      await db.prompts.delete(p.id);
    }
    await db.scenes.delete(id);
  });
}
```

## 六、交互规则

| 场景 | 行为 |
|------|------|
| 删除场景 | 场景 + 其下**活跃** prompt 同时标记 `deletedAt` |
| 恢复场景 | 场景 + 其下所有 prompt 清除 `deletedAt` |
| 单独删除 prompt | 仅该 prompt 标记 |
| 先后删 prompt 再删 scene → 恢复 scene | prompt 被恢复（用户恢复 scene = 意图恢复全部） |
| 恢复 prompt 但其 scene 也在回收站 | **弹窗选择目标场景**（默认创建"未分类"场景） |
| 编辑已删除 prompt | 自动恢复（清除 `deletedAt`） |
| 重复软删除 | No-op（不更新时间戳，防止绕过 30 天限制） |
| 搜索/筛选 | 不搜回收站内容 |
| 导出 | 不含已删除项 |
| 导入 | 强制清除 `deletedAt`，以活跃状态出现 |
| 快照 | 含已删除项（用于灾难恢复），恢复时保持原状态 |
| 清空回收站 | 永久删除所有软删除项 |
| 自动清理 | 下次打开扩展时清理 >30 天的旧项 |
