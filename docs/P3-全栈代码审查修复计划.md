### #1. testConnection 内部超时不生效

**文件**: `src/services/ai/openai.ts:114-133` + `src/services/ai/anthropic.ts:142-159`（需同步改两个文件）
**严重度**: 🔴 严重  
**影响**: 调用方传入 signal 时，内部 20s 超时完全绕过，请求可能无限挂起

**问题代码**:
```ts
const effectiveSignal = signal ?? internalCtrl.signal;
```
当 `signal` 非空时，内部 AbortController 被忽略。

**修复方案**: 始终叠加内部超时。注意：如果外部 signal **已经处于 aborted 状态**，`addEventListener('abort')` 不会触发（事件已发生），需要前置检查：
```ts
async testConnection(signal?: AbortSignal): Promise<...> {
  if (signal?.aborted) return { ok: false, latency: 0, error: '请求已取消' };
  const start = Date.now();
  const internalCtrl = new AbortController();
  const timeout = setTimeout(() => internalCtrl.abort(), 20000);
  const onExternalAbort = () => internalCtrl.abort();
  try {
    if (signal) signal.addEventListener('abort', onExternalAbort, { once: true });
    await this.client.chat.completions.create({...}, { signal: internalCtrl.signal });
    return { ok: true, latency: Date.now() - start };
  } catch (err) {
    const mapped = mapOpenAIError(err);
    return { ok: false, latency: Date.now() - start, error: mapped.message };
  } finally {
    clearTimeout(timeout);
    if (signal) signal.removeEventListener('abort', onExternalAbort);
  }
}
```

### #2. 键盘快捷键 hook 每次渲染重新注册

**文件**: `src/hooks/use-keyboard-shortcuts.ts`  
**严重度**: 🔴 严重  
**影响**: shortcuts 对象引用每帧变化，导致 keydown listener 每帧 cleanup + 重新 addEventListener

**修复方案**: 用 `useRef` 存储最新 shortcuts，事件处理时读取 `.current`，消除依赖：
```ts
export function useKeyboardShortcuts(shortcuts: ShortcutMap) {
  const shortcutsRef = useRef(shortcuts);
  useEffect(() => {
    shortcutsRef.current = shortcuts;
  });

  useEffect(() => {
    const handleKeyDown = (e: KeyboardEvent) => {
      const key = [e.ctrlKey || e.metaKey ? 'Ctrl' : '',
        e.shiftKey ? 'Shift' : '',
        (e.key || '').toUpperCase()]
        .filter(Boolean).join('+');

      const action = shortcutsRef.current[key];
      if (action) { e.preventDefault(); action(); return; }
      if (e.key === 'Escape' && shortcutsRef.current['Escape']) {
        shortcutsRef.current['Escape']();
      }
    };
    window.addEventListener('keydown', handleKeyDown);
    return () => window.removeEventListener('keydown', handleKeyDown);
  }, []); // 空依赖 — 只注册一次
}
```

### #4. CSP 缺少 `style-src` 指令

**文件**: `public-ext/manifest.json:44-46`  
**严重度**: 🔴 严重  
**影响**: MV3 显式 CSP 会覆盖默认值，Radix UI / Tailwind 动态样式可能被丢，极端情况白屏

**修复方案**: 补全 CSP：
```json
"content_security_policy": {
  "extension_pages": "script-src 'self'; style-src 'self' 'unsafe-inline'; object-src 'self'"
}
```
`'unsafe-inline'` 对 style-src 是安全的（无 XSS 风险），且 Radix UI 动画依赖内联样式。

### #5. settings 持久化 quota 静默丢弃

**文件**: `src/store/settingsStore.ts:51-54`  
**严重度**: 🔴 紧急  
**影响**: localStorage 配额满后 AI 配置保存静默失败，用户无感知。真正的紧急项是 settings——纯 5KB 配置写失败影响核心功能；snapshot 已有注释 "non-critical"，降为重要。

**修复方案**: Settings 迁移到 `chrome.storage.local`（扩展特权，~无限配额）：
```ts
async function persistSettings(settings: AISettings) {
  await chrome.storage.local.set({ [SETTINGS_KEY]: settings });
}
async function loadSettings(): AISettings | null {
  const data = await chrome.storage.local.get(SETTINGS_KEY);
  return data[SETTINGS_KEY] || null;
}
```
> ⚠️ **穿透性变更警告**：`persistSettings` 从同步变异步，`settingsStore` 内 `saveSettings`/`addProvider`/`updateProvider`/`removeProvider`/`setActiveProvider`/`clearSettings` 全部 6 个方法都调它，需逐一加 `await`。`loadSettings` 同理影响 `loadSettings()` action。
