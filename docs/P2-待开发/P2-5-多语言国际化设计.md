# P2-5：多语言国际化 (i18n)

> 2026-06-09

## Context

项目目前完全是中文硬编码（38 个文件，约 370 处中文字符串，约 120-140 个唯一 UI 字符串）。没有 i18n 库、没有翻译文件、没有语言切换机制。如果需要服务非中文用户，需要系统化引入国际化。

## 目标行为

1. 初始支持简体中文（zh-CN）和英文（en-US）两种语言
2. Header 或设置面板增加语言切换器
3. 所有用户可见字符串通过 `t('key')` 获取
4. 语言偏好存储到 localStorage
5. 代码层面支持后续添加更多语言（只需新增 JSON 文件）

## 实现方案

### 1. 技术选型：react-i18next

**依赖**：
```json
{
  "i18next": "^24",
  "react-i18next": "^15",
  "i18next-browser-languagedetector": "^8"
}
```

**理由**：
- React 生态事实标准
- 命名空间拆分（按组件/功能域拆分 JSON）
- 支持插值 `t('key', { count: 5 })`、复数和上下文
- 成熟的提取工具和编辑器插件
- 与 React 19 兼容

### 2. 目录结构

```
src/
  i18n/
    index.ts              # i18next 初始化 + 导出
    locales/
      zh-CN/
        common.json        # 通用按钮/Toast/确认框
        editor.json        # PromptEditor 特定
        settings.json      # AISettings 特定
        optimize.json      # OptimizePanel + 预设
        quality.json       # QualityAnalysisPanel
        export.json        # 导出导入相关
        version.json       # 版本历史
      en-US/
        common.json
        editor.json
        ...
```

### 3. 命名空间设计

| 命名空间 | 覆盖文件 | 预估 key 数 |
|----------|---------|------------|
| `common` | 所有文件的通用字符串（保存/取消/删除/确认...） | ~35 |
| `editor` | PromptEditor, VariableForm | ~15 |
| `settings` | AISettings, CloudBackupSettings | ~20 |

| `version` | VersionList, VersionDiff | ~8 |

| `header` | Header, Sidebar, StatusBar | ~12 |
| `home` | HomePage, PromptList, PromptCard | ~8 |

### 4. 初始化

**`src/i18n/index.ts`**：

```ts
import i18n from 'i18next';
import { initReactI18next } from 'react-i18next';
import LanguageDetector from 'i18next-browser-languagedetector';

// 按需导入英文翻译
import enCommon from './locales/en-US/common.json';
// ...

// 中文翻译直接内联（源语言，从代码中提取）
import zhCommon from './locales/zh-CN/common.json';
// ...

i18n
  .use(LanguageDetector)
  .use(initReactI18next)
  .init({
    resources: {
      'zh-CN': { common: zhCommon, /* ... */ },
      'en-US': { common: enCommon, /* ... */ },
    },
    fallbackLng: 'zh-CN',
    defaultNS: 'common',
    interpolation: { escapeValue: false },
    detection: {
      order: ['localStorage', 'navigator'],
      caches: ['localStorage'],
      lookupLocalStorage: 'ai-prompt-manager-lang',
    },
  });

export default i18n;
```

### 5. 使用方式

```tsx
// 函数组件
import { useTranslation } from 'react-i18next';

function PromptEditor() {
  const { t } = useTranslation(['editor', 'common']);
  return <Button>{t('common:save')}</Button>;
}

// 非组件上下文（toast / service / error message）
import i18n from '@/i18n';
i18n.t('common:saveSuccess');
```

### 6. 语言切换器

**`src/components/settings/LanguageSettings.tsx`**：

```tsx
import { useTranslation } from 'react-i18next';

export default function LanguageSettings() {
  const { i18n } = useTranslation();
  return (
    <select value={i18n.language} onChange={e => i18n.changeLanguage(e.target.value)}>
      <option value="zh-CN">简体中文</option>
      <option value="en-US">English</option>
    </select>
  );
}
```

放置于 AI 设置对话框中作为新 Tab，或放在 Header 中作为图标按钮。

### 7. 迁移策略

分 4 个阶段，每个阶段独立可交付：

**Phase 1 — 基础设施**：安装依赖、建目录、写 `i18n/index.ts`、创建 `zh-CN/common.json`

**Phase 2 — 通用字符串**：替换 8 个高频复用字符串（保存成功/取消/删除...）覆盖全部 38 个文件

**Phase 3 — 功能域迁移**：按命名空间逐个文件迁移（editor → settings → optimize → quality → ...）

**Phase 4 — 英文翻译**：编写 `en-US/*.json`

### 8. 不需要翻译的内容

| 类型 | 原因 |
|------|------|
| AI 系统提示词（`ai/index.ts` 第 46-53 行等） | 这些是发给 AI 的 prompt，不需要翻译 |
| 预设优化指令（`OptimizePanel.tsx` PRESETS） | 发给 AI 的中文指令，翻译后会改变 AI 行为 |
| 质量分析正则中的 CJK 范围 | 技术常量 |
| 开发者调试日志 | 非用户可见 |

这些内容从代码中提取到单独的常量文件即可（如 `src/constants/prompts.ts`），不需要进入 i18n 系统。

## 评审发现与修订 (2026-06-09)

### 1. 字符串数量低估 ~30%

**问题**：文档估计 ~370 处，实际统计约 483 处中文字符串。主要遗漏在 `tagSuggest.ts`（27 处 AI 标签描述）、`promptAnalyzer.ts`（56 处而非 40）和 `OptimizePanel.tsx` 的 PRESETS（6 处长文本）未计入。

**修正**：修订估算为 ~480 处字符串（约 180-200 个唯一 UI key）。时间评估据此调整。

### 2. ai/index.ts 中 3 条用户可见 Error 误分类

**问题**：设计说 `ai/index.ts` 所有中文都不翻译（因为是 AI prompt）。但第 39/79/110 行的 3 个 `throw new Error('AI 未配置...')` 是用户可见的错误提示，需要翻译。

**修正**：`src/services/ai/index.ts` 中 user-facing error 改用 `i18n.t('ai:notConfigured')` + fallback 中文。System prompt 模板保持中文不翻译（发给 AI 的）。

### 3. react-i18next 版本号修正

**问题**：设计写了 `i18next: ^24` + `react-i18next: ^15`，但最新 react-i18next@15 的 peerDependency 要求 i18next >= 25.4.1。

**修正**：指定 `i18next: ^25` + `react-i18next: ^15`。

### 4. "确认" vs "确定" 事实错误

**问题**：设计中"高度复用"表列了"确认 ~3 次"。代码中实际是"确定"（7 次），"确认"不存在。

**修正**：更正高频复用表，将"确认"替换为"确定"。

### 5. "删除" 的复合字符串问题

**问题**：Phase 2 替换的 8 个高频字符串中，"删除"出现 28 次，但嵌在复合字符串中（"删除场景"、"删除提示词"、"删除失败"、"删除版本"、"删除成功"），不能简单替换。

**修正**：复合字符串处理为独立 i18n key（如 `scene:deleteScene`、`prompt:deletePrompt`），而非组合 `t('common:delete') + t('scene:scene')`。Phase 2 实际影响 19 个文件而非 38 个。

### 6. 13 条服务层 Error 消息

**问题**：设计只提到 versionService.ts 一条，实际有 13 条 `throw new Error('中文')` 分布在 5 个文件中（versionService 5 条、ai/index 3 条、export-import 2 条、promptService 1 条、AISettings 2 条）。

**修正**：Phase 3 迁移时统一处理。服务层用 `import i18n from '@/i18n'` + `i18n.t()` pattern。
