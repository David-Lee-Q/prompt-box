## 一、国际竞品深度洞察

### 1.1 TrueFoundry — 企业级 AI 基础设施平台

| 维度 | 详情 |
|------|------|
| **官网** | truefoundry.com/prompt-management |
| **定位** | 企业级 AI 基础设施，提示词管理 + AI Gateway + 模型部署三位一体 |
| **一句话** | 不只管 Prompt，连模型部署、网关、代理一起管了 |
| **目标用户** | 500+ 人企业的 AI/ML 团队，需要 SOC 2/HIPAA/GDPR 合规的组织 |
| **融资** | 2130 万美元（Intel Capital 领投 A 轮） |
| **团队** | ~100 人 |
| **总部** | 旧金山 |

**核心功能：**
- 集中式 Prompt Registry + 语义版本控制 + 一键回滚
- 多环境晋升（dev → staging → prod）+ 审批工作流
- 模板变量 `{{variable}}` 支持 + 代码片段生成器（Python/Node.js/cURL）
- AI Gateway（延迟 3-4ms，单 vCPU 350+ RPS）
- 模型部署 + MCP 服务器注册表 + 代理编排
- 可观测性（OpenTelemetry、GPU 监控、成本追踪）
- 输入/输出护栏 + 语义缓存 + 故障转移
- 结构化输出（JSON Schema）

**定价：**
- Free：10 个 prompt，5 个 MCP 服务器
- Pro：$499/月，无限 prompt，100 万工具调用
- Pro+：$2,999/月
- Enterprise：自定义（含本地/气隙部署）

**优势：** 基础设施层能力极强，Gateway 性能护城河深；SOC 2/HIPAA/GDPR 全齐
**劣势：** 499 美元/月起步，对纯 prompt 管理场景过重；更像 AI infra 而非 prompt 管理工具
**对我们的启示：** 它的 prompt 管理功能是 AI Gateway 的附属，不是独立产品。我们在 prompt 管理的深度上（编辑体验、变量系统、质量分析）远超它。

## 二、国内市场深度洞察

### 2.1 市场总体判断

**国内市场特征：**
- 没有明确的市场领导者 —— 赛道极早期且高度碎片化
- 云平台内置工具占主导 —— 百度千帆、阿里百炼的 prompt 管理功能最完善，但平台锁定
- 开源工具活跃但缺乏商业支持 —— Prompt Optimizer（26K stars）、AI Gist 质量很高，但都是个人项目
- 多数工具面向个人用户，团队协作功能稀缺
- **没有中国版 Langfuse（可观测性 + prompt 管理）或 Humanloop（企业级）**

### 2.2 独立 SaaS / Web 端产品

#### 2.2.1 PrompterHub (prompterhub.cn)
- **定位**：AI Prompt 管理社区平台
- **特点**：Prompt 创作 + 社区 + KOL 精选模板 + 浏览器扩展
- **用户**：个人 AI 用户、创作者
- **定价**：免费
- **对比**：类似 PromptBase + AIPRM 的社区模式

#### 2.2.2 PromptEditor (prompteditor.cn)
- **公司**：南京三足金乌网络科技有限公司
- **定位**：免费的 AI Prompt 写作和编辑工具
- **特点**："Prompt 专家"一键生成立即 Prompt、Markdown 编辑器、AB 对比、版本管理、100+ 模型接入、质量测试评估、导出 Word
- **用户**：个人用户、Prompt 工程师
- **定价**：免费
- **对比**：编辑器体验好；有版本管理和 AB 对比；但无团队协作；功能跟 AI Prompt Manager 有重叠

#### 2.2.3 PromPool (nerdtechnic.com) — 台湾
- **公司**：恩梯科技股份有限公司
- **定位**：AI Prompt 团队协作管理平台
- **特点**：Git 风格版本控制 + 回滚、团队协作、变量管理（自动识别提取）、版本评分、公开分享链接、工具组分群
- **语言**：繁中/简中/英/日/韩
- **定价**：免费（TWD $0）
- **对比**：国内最接近企业级团队工具的 SaaS；目前免费策略激进

#### 2.2.4 PromptHub (prompthub-app.vercel.app)
- **特点**：开源 AI Prompt & Skill 管理工作台
- **亮点**：Prompt 管理 + Skill 商店 + 版本控制 + 多模型测试 + 一键安装到 15+ AI 编程工具
- **用户**：使用 AI 编程工具的开发者
- **定价**：免费开源
- **对比**：跟 AI Prompt Manager 定位最接近！支持 Claude Code/Cursor/Windsurf 等工具的一键安装

### 2.3 开源桌面端 / 本地工具

| 产品 | 定位 | 技术栈 | Stars | 亮点 |

### 3.2 AI Prompt Manager 的位置

我们目前定位在**左下角**——个人用户、功能聚焦（编辑+管理+版本）。空白方向有两个：

```
                机会方向 1：向上走团队版
                    ↓
  ┌──────────────────────────────────┐
  │  个人版（当前）                      │
  │  ✅ 编辑 + 版本 + 变量             │
  │  ✅ AI 优化 + 测试 + 评分          │
  │  ✅ 质量分析 + 导出 + 搜索         │
  │  ❌ 协作 + RBAC + 审批             │
  └──────────────────────────────────┘
                    ↓
                机会方向 2：向右深耕专业度
```

### 3.3 差异化机会

从竞品分析中提炼出的空白地带：

| 空白地带 | 竞品现状 | 我们的机会 |
|---------|---------|-----------|
| **编辑器内实时质量分析** | 竞品全部依赖外部评估（API 调用），无离线静态分析 | ✅ P2 Step 15 已规划，独有 |
| **本地优先 + 免 API** | 所有国际竞品都是 SaaS，依赖 API | ✅ 纯前端 PWA，完全离线可用 |
| **个人免费工具** | PromptLayer Free 仅 2,500 请求/月；TrueFoundry 10 prompt | ✅ 我们可提供更慷慨的免费版 |
| **中文 Prompt 优化** | PromptFluent 20K 库全是英文 | ✅ 国内竞品无结构化版本管理 |
| **变量模板系统** | TrueFoundry/PromptLayer 有但浅 | ✅ P0 深度规划 |
| **Agent 导出** | 竞品全部通过 API 调用，无离线导出 | ✅ P2 4 种格式导出 |
| **MCP Server 集成** | PromptOT 最强但我们没做 | ✅ 未来可扩展方向 |

### 3.5 核心结论

```
市场验证：
  ✅ 国际赛道确认存在 —— 8 家获融资竞品，市场年增 29.6%
  ✅ 国内无领导者 —— 云平台锁定 + 个人工具碎片化
  ✅ 个人工具层有空间 —— 国际竞品集中在企业级（$499+/月）

差异化立足点：
  1. 编辑器内实时质量分析 —— 独有，竞品无
  2. 本地优先 + 零 API 成本 —— 个人用户友好
  3. 中文支持 + 国内用户习惯 —— 国内竞品管理深度不足
  4. 降低功能复杂度 —— 不做企业级重量功能，专注个人编辑体验

该做 vs 不该做：
  ✅ 深耕编辑体验 + 质量分析 + 变量系统
  ✅ 做中文 Prompt 优化的最佳工具
  ✅ 合理定价（参考 PromptOT $29/月 和 PromptLayer $49/月）
  ❌ 不做企业协作/RBAC/审批（资源有限，先聚焦个人）
  ❌ 不做 AI Gateway/模型部署（偏离定位且成本高）
  ❌ 不做 Prompt 市场/社区（启动成本高，先做好工具本身）
```
